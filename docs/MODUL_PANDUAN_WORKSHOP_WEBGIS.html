1. Latar Belakang & Paradigma Baru Pengembangan GIS

Secara konvensional, pembuatan aplikasi WebGIS memerlukan penguasaan mendalam di berbagai bidang: kartografi geodesi, struktur data geospasial (GeoJSON, WGS84), pemrograman frontend web (HTML/CSS/JS), library peta Leaflet, serta administrasi server. Akibatnya, kurva pembelajaran pembuatan WebGIS menjadi sangat terjal bagi pemula.

Hadirnya era Agentic AI (AI Otonom) dan Generative AI Multimodal mengubah paradigma ini. Pengembang kini tidak lagi harus mengetik ratusan baris kode JavaScript secara manual, melainkan bertindak sebagai Arsitek Sistem (System Architect) dan Kurator Kualitas Data (Quality Assurer). AI mengambil alih pekerjaan repetitif penulisan skrip dan perbaikan bug, sementara manusia memegang kendali atas validitas data, metodologi keilmuan, dan logika spasial.

3. Fase 1: AI Web Scraping & Ekstraksi Data Spasial

Banyak informasi geospasial tematik (situs bersejarah, cagar budaya, fasilitas kesehatan, atau potensi wisata) tersebar dalam bentuk artikel narasi, tabel HTML Wikipedia, atau dokumen berita yang tidak menyediakan tombol ekspor data spasial.

A. Metode Parsing Cepat Menggunakan AI (Tanpa Koding)

Peserta dapat menyalin teks atau tabel dari peramban web, lalu memberikan prompt terstruktur kepada ChatGPT atau Google Gemini: 

"Bertindaklah sebagai Data Extraction Specialist. 
Berikut adalah teks daftar objek peninggalan bersejarah yang saya salin dari internet:
[TEMPELKAN TEKS / TABEL DARI SITUS WEB DI SINI]

Tugasmu:
1. Ekstrak entitas tersebut ke dalam format JSON array yang rapi.
2. Setiap objek wajib memiliki atribut: id, nama_objek, tipe_kategori, tahun_pembangunan, kota_kabupaten, latitude, longitude, deskripsi_ringkas, sumber_referensi.
3. Estimasi koordinat latitude dan longitude (CRS WGS84) titik fisik objek tersebut.
4. Pastikan koordinat berada di wilayah Indonesia (Latitude antara 6 LU s/d 11 LS, Longitude antara 95 BT s/d 141 BT)."

B. Metode Otomasi Python Scraping (Untuk Halaman Berulang)

Untuk data yang memiliki ratusan baris, AI dapat diminta membuatkan skrip Python ringan menggunakan pustaka BeautifulSoup dan requests: 

import requests
from bs4 import BeautifulSoup
import json

url = "https://id.wikipedia.org/wiki/Daftar_cagar_budaya_di_Indonesia"
headers = {'User-Agent': 'Mozilla/5.0'}
response = requests.get(url, headers=headers)
soup = BeautifulSoup(response.text, 'html.parser')

4. Fase 2: Koreksi & Pemeriksaan Keakuratan Data (Anti-Hallucination)

⚠️ PERINGATAN KRITIS TENTANG HALUSINASI AI DALAM GIS
Model AI generatif dapat mengarang nilai desimal koordinat jika tidak memiliki data spasial primer. Peserta workshop wajib memverifikasi data sebelum diintegrasikan ke WebGIS.
Gambar 1: Alur 4 Tahap Verifikasi Keakuratan Data Geospasial
  1. Antisipasi Lat/Lng Inversion (Tertukar Lintang dan Bujur):
    Kesalahan paling jamak pemula: menaruh nilai bujur (misal: 110.36) pada kolom latitude dan nilai lintang (-7.80) pada longitude. Akibatnya, titik peta terlempar ke Samudera Hindia atau kutub.
  2. Verifikasi Toponimi Kuno vs Modern:
    Nama tempat bersejarah seringkali berbeda dengan batas administratif modern. Pastikan koordinat mengarah langsung pada tapak fisik cagar budaya, bukan sekadar kantor kecamatan setempat.
  3. Klasifikasi Tingkat Keyakinan (Confidence Level):
    • Tinggi: Objek memiliki bukti fisik cagar budaya nasional, terdaftar di Kemendikbudristek/BPCB, dan koordinat diverifikasi GPS/satelit.
    • Sedang / Interpretatif: Objek bersumber dari teks naskah kuno/babad di mana sisa fondasi fisik belum ditemukan secara utuh.

5. Fase 3: Panduan Melampirkan Dataset Mandiri Peserta (Untuk Ujian)

Untuk menguji kompetensi mandiri, setiap peserta diwajibkan menyiapkan data tematik mereka sendiri (misal: sebaran kuliner khas, cagar budaya kota asal, puskesmas, atau titik rawan bencana).

Format Template Spreadsheet (Excel / CSV) Ujian Peserta:

id nama_objek kategori latitude longitude tahun_awal tahun_akhir foto_url sumber_data
obj-01 Masjid Agung Demak ibadah -6.8946 110.6373 1479 9999 https://...jpg BPCB Jawa Tengah
obj-02 Benteng Somba Opu benteng -5.1897 119.3982 1525 1669 https://...jpg Balai Cagar Budaya Sulsel

Cara Integrasi File Peserta Melalui Antigravity:

Peserta cukup menyimpan file spreadsheet tersebut sebagai data/dataset_mandiri.csv di dalam workspace proyek, lalu mengirimkan perintah ke Antigravity: 

"Saya sudah melampirkan file data mandiri saya di data/dataset_mandiri.csv.
Tolong baca file tersebut, verifikasi integritas koordinatnya, konversikan menjadi file data/sites.json berstandar WGS84, dan hubungkan ke dalam WebGIS Leaflet kita lengkap dengan penanda kustom dan popup foto."

6. Fase 4: Prototyping UI Cepat di Google AI Studio

Sebelum menginstruksikan Antigravity melakukan coding, peserta menggunakan Google AI Studio untuk merancang identitas visual yang profesional:

  • Eksplorasi Skema Warna Tematik: Hijau zamrud (#0f4c3a) dan aksen emas (#d97706) untuk sejarah Islam; Biru bahari untuk data maritim/perikanan.
  • Desain Mobile-First: Menginstruksikan AI Studio untuk merancang Bottom Sheet interaktif dan kartu detail foto agar tidak memakan ruang pandang peta di layar handphone (viewport 360px).

7. Fase 5: Eksekusi Kode Otonom di Google Antigravity & Debugging

Antigravity bertindak sebagai rekan pair programming otonom yang bekerja langsung di dalam komputer peserta:

  1. Membaca Basis Kode Proyek: Antigravity membaca seluruh file di workspace secara kontekstual.
  2. Penyusunan Modul Modular: Membagi kode menjadi modul terpisah: map.js (manajemen Leaflet), timeline.js (slider temporal), dan detail.js (panel drawer).
  3. Optimasi Performa Gambar (Anti-Lag): Menerapkan loading="lazy" pada foto agar WebGIS tetap ringan dan cepat saat diakses di perangkat seluler.
  4. Penyempurnaan Bug Responsif: Memperbaiki konflik tata letak (misal tombol zoom yang tertutup panel bawah) secara instan.

8. Fase 6: Otomasi Publikasi & Hosting Gratis di GitHub Pages

Peserta tidak perlu menginstal Git GUI atau mengetik perintah terminal rumit. Cukup minta Antigravity: 

"Tolong push semua perubahan kode dan data terbaru ke repositori GitHub saya di branch main."

Langkah Aktivasi GitHub Pages (Sekali Klik):

  1. Buka repositori GitHub Anda di web browser.
  2. Masuk ke menu Settings → pilih bilah Pages.
  3. Pada opsi Branch, pilih main dan folder / (root) → Klik Save.
  4. Dalam 1–2 menit, WebGIS Anda resmi mengudara secara global di: https://username.github.io/nama-repo/.
💡 KEUNGGULAN SINKRONISASI OTOMATIS
Setiap kali peserta meminta Antigravity menambah data baru atau memperbaiki fitur, Antigravity akan otomatis melakukan commit dan push. Website online peserta akan ter-update secara otomatis tanpa perlu deployment manual!

9. Rekomendasi Alat AI Lain & Ekosistem Google

Bagi pengguna yang memiliki langganan Google One AI Premium (Gemini Advanced/Pro), fitur-fitur berikut dapat dimanfaatkan secara maksimal:

  • Gemini di Google Docs (Help Me Write): Salin teks panduan ini ke Google Docs. Gunakan fitur "Help me write" untuk memformat modul, membuat ringkasan, dan memanfaatkan "Insert → Image → Help me create an image" (Imagen 3) untuk menghasilkan ilustrasi kustom. Unduh langsung dalam format .docx atau .pdf.
  • Google NotebookLM (100% Gratis berbasis Gemini 1.5 Pro): Unggah file Markdown modul ini ke NotebookLM. AI akan otomatis membuatkan lembar tanya jawab (FAQ), panduan belajar (*Study Guide*), bahkan ringkasan podcast audio untuk peserta workshop.
  • Gamma.app (AI Pembuat Dokumen & Presentasi): Cukup tempelkan teks Markdown modul ini ke Gamma.app. AI akan menyusunnya menjadi dokumen PDF atau slide presentasi interaktif lengkap dengan kartu visual otomatis.
