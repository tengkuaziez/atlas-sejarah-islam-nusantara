Bagian I: Pendahuluan & Landasan Teori

1.1 Transformasi Paradigma Geospasial di Era Artificial Intelligence

Sistem Informasi Geografis Berbasis Web (WebGIS) telah menjadi media paling efektif dalam mendemokratisasikan data geospasial kepada publik. Melalui peramban web tanpa memerlukan instalasi perangkat lunak GIS desktop yang berat, pengguna awam dapat mengeksplorasi data sebaran, pola keruangan, hingga analisis temporal.

Namun, kurva pembelajaran pengembangan WebGIS konvensional sangat terjal. Pengembang dituntut menguasai kartografi geodesi (sistem proyeksi, datum WGS84, koordinat desimal), penataan format data (GeoJSON, TopoJSON), pemrograman frontend modern (HTML5, CSS Flexbox/Grid, JavaScript asynchronous), pustaka pemetaan (Leaflet.js, OpenLayers), serta manajemen server dan deployment (Git, GitHub, web server).

Hadirnya Generative AI dan Agentic AI Coding Assistant tidak menghilangkan kaidah keilmuan geospasial, melainkan mentransformasi alur kerja: pengembang tidak lagi disibukkan oleh penulisan kode sintaksis baris-demi-baris yang rawan galat (syntax error), melainkan fokus sebagai Arsitek Sistem (System Architect) dan Kurator Kualitas Data (Quality Assurer).

1.2 Capaian Pembelajaran Workshop (Learning Outcomes)

Setelah menyelesaikan modul pelatihan ini selama 120 menit, peserta diharapkan mampu:

  • Capaian Kognitif: Memahami arsitektur alur kerja multi-AI dalam rekayasa geospasial serta prinsip dasar mitigasi halusinasi toponimi.
  • Capaian Psikomotorik: Mampu mengekstrak data tabel web menjadi JSON spasial terstruktur, mengoreksi anomali pembalikan koordinat (lat/lng inversion), merancang antarmuka Leaflet interaktif, dan mempublikasikan kode ke GitHub Pages secara otonom.
  • Capaian Afektif: Memiliki etika integritas data ilmiah dengan melampirkan atribusi sumber, lisensi berkas terbuka, dan indikator kepastian historis (confidence level).

Bagian III: Ekstraksi Data Spasial (AI Web Scraping)

Tantangan utama pemetaan tematik adalah ketiadaan data spasial siap pakai (seperti format SHP atau GeoJSON) dari institusi resmi. Sebagian besar data cagar budaya, fasilitas kesehatan, atau pariwisata tersimpan dalam format teks artikel, siaran pers, atau tabel Wikipedia.

Gambar 2: Alur Konversi Data Semi-Terstruktur Web Menjadi Standar Geospasial

3.1 Metode AI Table & Text Parsing (Tanpa Koding)

Peserta dapat menyalin tabel atau teks panjang dari halaman web, kemudian menggunakan prompt terstruktur pada model AI (ChatGPT atau Gemini): 

"Anda adalah Data Extraction Specialist. Berikut teks daftar cagar budaya yang saya salin:
[TEMPELKAN TEKS / TABEL DARI WEBSITE]

Tugas:
1. Ekstrak menjadi format JSON array murni tanpa narasi pembuka/penutup.
2. Setiap objek wajib memuat atribut: id, nama_objek, kategori, tahun_pembangunan, latitude, longitude, deskripsi, sumber_referensi.
3. Estimasi koordinat geografis dalam sistem proyeksi CRS WGS84 (EPSG:4326).
4. Verifikasi bahwa nilai Latitude bernilai negatif untuk belahan bumi selatan Indonesia (0 s/d -11) dan Longitude berkisar antara 95 s/d 141 BT."

Bagian IV: Protokol Validasi Geospasial (Anti-Hallucination)

⚠️ PERINGATAN KRITIS: KARAKTERISTIK HALUSINASI AI PADA DATA SPASIAL
Model bahasa besar (LLM) bekerja memprediksi probabilitas kata berikutnya, bukan menghitung posisi geodesi di permukaan bumi. Oleh sebab itu, AI sangat rentan mengarang desimal koordinat geografis. Seluruh data spasial yang dihasilkan oleh AI WAJIB melalui protokol pengujian berikut sebelum dimasukkan ke peta.
Gambar 3: Empat Pilar Protokol Verifikasi Integritas Data Geospasial

4.1 Uji Inversi Koordinat (Latitude / Longitude Flip Test)

Kesalahan paling lazim yang dilakukan pemula maupun sistem AI adalah tertukarnya kolom lintang (Latitude) dan bujur (Longitude). Wilayah Negara Kesatuan Republik Indonesia berada pada batas koordinat (Bounding Box):

  • Latitude ($\phi$): $+6^\circ ext{ LU}$ (Pulau Weh/Sabang) hingga $-11^\circ ext{ LS}$ (Pulau Rote).
  • Longitude ($\lambda$): $+95^\circ ext{ BT}$ (Ujung barat Sumatera) hingga $+141^\circ ext{ BT}$ (Merauke).

Aturan Baku: Jika nilai latitude bernilai positif di atas $6$ atau bernilai lebih dari $90$ (misal $110.36$), berarti koordinat tertukar dengan longitude! Jika tidak dikoreksi, titik akan terlempar ke Samudera Hindia atau kutub bumi.

4.2 Verifikasi Toponimi Fisik vs Administrasi Modern

Pencarian lokasi sejarah di peta modern seringkali keliru mengarah ke pusat kecamatan atau kantor bupati masa kini. Contoh: Sunda Kelapa harus diposisikan di muara pelabuhan tua Jakarta Utara (bukan Monas), dan Bandar Kuno Barus harus diletakkan pada situs arkeologi Makam Papan Tinggi / Lobu Tua di Tapanuli Tengah (bukan terminal bus kota).

4.3 Penentuan Indikator Kepastian Data (Confidence Level)

Tingkat Kepastian Kriteria Arkeologis & Geodesi Penetapan Tampilan Peta
Tinggi (High) Struktur fisik bangunan cagar budaya masih berdiri utuh; koordinat diverifikasi melalui GPS geodetik / citra satelit resolusi tinggi; didukung SK Cagar Budaya Nasional. Titik solid; poligon batas definitif terverifikasi peta arsip resmi.
Sedang (Medium) Sisa fondasi berupa reruntuhan arkeologis ditemukan; toponimi didukung prasasti/laporan kolonial (Oudheidkundige Dienst), namun batas lingkungan luar bersifat estimasi. Titik solid; poligon batas diberi garis putus-putus (*dashed line*).
Interpretatif Hanya disebutkan dalam naskah babad/hikayat tanpa sisa arsitektur fisik yang dapat diidentifikasi secara pasti di lapangan. Dilarang membuat batas administratif rekaan; wajib diberi label perkiraan wilayah mandala.

Tolong lakukan audit terhadap berkas tersebut:
1. Validasi nilai latitude dan longitude pada setiap baris data agar berada dalam Bounding Box Indonesia.
2. Konversikan berkas CSV tersebut menjadi format 'data/sites.json' berstandar GeoJSON/WGS84.
3. Sambungkan layer ini ke modul pemetaan Leaflet pada 'assets/js/map.js' lengkap dengan ikon penanda sesuai kategori dan popup kartu foto yang responsif."

Bagian VI: Perancangan UI & Pemrograman Otonom (Agentic Coding)

Gambar 4: Rancangan Tata Letak Wireframe Antarmuka Mobile-First WebGIS

6.1 Arsitektur Modular Kode JavaScript

Aplikasi dibangun tidak dalam satu berkas raksasa, melainkan modular agar mudah dipelihara dan diperbaiki:

  • assets/js/map.js: Mengatur inisialisasi peta Leaflet, pergeseran pusat pandang (zoom to bounding box), penanganan marker cluster, dan pergantian basemap.
  • assets/js/timeline.js: Mengatur kontrol linimasa dinamis, pemutaran animasi otomatis (play/pause), dan penyaringan layer berdasarkan tahun historis.
  • assets/js/detail.js: Mengelola panel informasi detail (*drawer*), penayangan foto resolusi tinggi, data silsilah penguasa, dan daftar referensi akademik.
  • assets/js/filters.js: Mengatur penyaringan spasial berdasarkan kepulauan dan kategori situs.

Bagian VII: Publikasi Terbuka di GitHub Pages

Gambar 5: Siklus Otomasi Continuous Deployment Menggunakan GitHub Pages

7.1 Langkah Aktivasi Publikasi

  1. Pastikan seluruh berkas telah di-push ke repositori GitHub pada branch main.
  2. Buka repositori Anda di browser web → Masuk ke menu Settings → Pilih bilah Pages di sebelah kiri.
  3. Pada menu Build and deployment → Branch: pilih main dan direktori / (root) → Klik Save.
  4. Tunggu 60–120 detik, muat ulang halaman. Alamat situs publik Anda akan aktif pada tautan:
    https://[nama-pengguna].github.io/[nama-repositori]/

Bagian IX: Glosarium Istilah & Rujukan Akademik

Glosarium Geospasial & Web Development:

  • CRS (Coordinate Reference System): Sistem koordinat untuk memproyeksikan permukaan lengkung bumi ke dalam representasi matematis.
  • WGS84 (EPSG:4326): Datum geodesi standar global yang digunakan oleh GPS dan Leaflet.js dengan unit derajat desimal.
  • GeoJSON: Format standar berbasis JSON untuk menyandikan aneka struktur data geografis (Point, LineString, Polygon, FeatureCollection).
  • Lat/Lng Inversion: Galat fatal akibat tertukarnya urutan lintang (Latitude) dan bujur (Longitude), menyebabkan fitur spasial berpindah posisi ke belahan bumi lain.
  • Native Lazy Loading: Atribut peramban (loading="lazy") yang menunda pengunduhan gambar hingga pengguna menggulir layar mendekati posisi gambar tersebut, sangat krusial untuk menghemat memori perangkat seluler.
  • Agentic AI: Model kecerdasan buatan tingkat lanjut yang memiliki kapabilitas menggunakan alat (*tool use*), mengeksekusi perintah terminal, membaca basis kode, dan memperbaiki galat pemrograman secara mandiri.
