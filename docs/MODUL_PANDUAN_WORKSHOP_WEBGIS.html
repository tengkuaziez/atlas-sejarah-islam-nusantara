Bagian I: Pendahuluan & Landasan Teori

1.1 Mengapa Alur Kerja Ini Menawarkan Simplisitas Nyata?

Tantangan paling menyita waktu dan kerap menjadi momok bagi peserta pelatihan WebGIS non-IT adalah Friksi DevOps dan Deployment. Secara tradisional, setiap kali seorang peneliti ingin memperbaiki satu baris koordinat atau mengganti foto cagar budaya di peta, ia diwajibkan melewati prosedur manual yang rumit:

  1. Membuka terminal Git Bash atau aplikasi command line.
  2. Mengetik sintaks terminal yang rawan salah: git status, git add ., git commit -m "update", dan git push origin main.
  3. Jika terjadi konflik atau galat otentikasi Git, pemula kerap frustrasi dan terpaksa melakukan metode darurat: mengunduh ZIP, menghapus repositori, atau menyeret file satu-per-satu (*drag and drop*) ke antarmuka web GitHub.
  4. Mengulangi kembali konfigurasi hosting dan menunggu pengecekan ulang.

Melalui paradigma Agentic AI (Google Antigravity), seluruh friksi administratif ini dihapuskan secara total. Pengembang tidak perlu lagi membuka terminal, tidak perlu mengetik perintah Git, dan tidak perlu mengunggah berkas ulang ke peramban. AI bertindak sebagai teknisi DevOps otonom yang memproses, memeriksa sintaksis, melakukan commit, dan mengeksekusi push ke GitHub hanya berdasarkan satu kalimat instruksi santai.

1.2 Capaian Pembelajaran Workshop (Learning Outcomes)

  • Capaian Kognitif: Menguasai konsep dasar arsitektur multi-AI geospasial serta mekanisme Continuous Deployment (CD) otomatis berbasis GitHub Pages.
  • Capaian Psikomotorik: Mampu melakukan scraping data tabel web menjadi GeoJSON, memvalidasi koordinat anti-halusinasi, merakit antarmuka Leaflet mobile, dan memperbarui website live secara instan via instruksi AI.
  • Capaian Afektif: Memiliki etika integritas data ilmiah (atribusi lisensi terbuka dan indikator confidence level) serta kepercayaan diri membangun solusi geospasial modern tanpa hambatan koding rumit.

Gambar 2: Alur Konversi Data Semi-Terstruktur Web Menjadi Standar Geospasial

3.1 Metode AI Table & Text Parsing (Tanpa Koding)

Peserta dapat menyalin tabel dari peramban, lalu mengirimkan instruksi terstruktur ke model AI: 

"Anda adalah Data Extraction Specialist. Berikut teks daftar cagar budaya yang saya salin:
[TEMPELKAN TEKS / TABEL DARI WEBSITE]

Tugas:
1. Ekstrak menjadi format JSON array murni tanpa narasi pembuka/penutup.
2. Setiap objek wajib memuat atribut: id, nama_objek, kategori, tahun_pembangunan, latitude, longitude, deskripsi, sumber_referensi.
3. Estimasi koordinat geografis dalam sistem proyeksi CRS WGS84 (EPSG:4326).
4. Verifikasi bahwa nilai Latitude bernilai negatif untuk wilayah Indonesia (0 s/d -11) dan Longitude berkisar antara 95 s/d 141 BT."

Gambar 3: Empat Pilar Protokol Verifikasi Integritas Data Geospasial

4.1 Uji Inversi Koordinat (Latitude / Longitude Flip Test)

Wilayah Indonesia berada pada rentang batas koordinat geografis (Bounding Box):

  • Latitude (φ): Antara $+6^\circ ext{ LU}$ (Sabang) hingga $-11^\circ ext{ LS}$ (Rote).
  • Longitude (λ): Antara $+95^\circ ext{ BT}$ hingga $+141^\circ ext{ BT}$.

Aturan Baku: Jika nilai latitude bernilai positif di atas $6$ atau bernilai lebih dari $90$ (misal $110.36$), berarti koordinat tertukar dengan longitude! Jika tidak dikoreksi, titik akan terlempar ke Samudera Hindia atau kutub bumi.

4.2 Standarisasi Indikator Kepastian Data (Confidence Level)

Tingkat Kepastian Kriteria Arkeologis & Geodesi Penetapan Tampilan Peta
Tinggi (High) Struktur fisik cagar budaya berdiri utuh; koordinat terverifikasi GPS geodetik / citra satelit resolusi tinggi; didukung SK Cagar Budaya. Titik solid; poligon batas definitif terverifikasi peta arsip resmi.
Sedang (Medium) Sisa reruntuhan arkeologis ditemukan; toponimi didukung prasasti/laporan arsip, namun batas lingkungan luar bersifat perkiraan. Titik solid; poligon batas diberi garis putus-putus (*dashed line*).
Interpretatif Disebutkan dalam naskah babad tanpa bukti sisa fisik yang utuh. Dilarang membuat batas administratif rekaan; label perkiraan mandala.

Gambar 5: Transformasi Radikal Alur Deployment Konvensional Menjadi Zero-Manual Deployment

7.1 Perbandingan Alur Kerja Tradisional vs Agentic AI

Aktivitas / Skenario Metode Konvensional (Manual) Metode Agentic AI (Otonom)
Menambah 5 Titik Data Baru Buka file JSON secara manual, atur format koma/kurung kurawal (rawan galat sintaksis), buka terminal, ketik perintah git add, commit, push. Cukup katakan: "Tolong tambahkan 5 data cagar budaya ini dan langsung update ke GitHub." AI mengedit berkas dan mengeksekusi push otomatis.
Memperbaiki Bug CSS di HP Cari file style.css baris demi baris, uji di browser, buka kembali git bash, commit ulang, push ulang. Cukup katakan: "Tombol zoom ketutupan drawer di HP, tolong naikkan posisinya dan deploy sekarang." Selesai dalam 30 detik.
Penanganan Galat Git Pengembang bingung memecahkan pesan galat terminal (merge conflict, head detached). AI membaca output log terminal, menganalisis status repositori, dan menyelesaikan sinkronisasi branch secara otomatis.

7.2 Konsep "Set Once, Continuous Auto-Deploy Forever"

Peserta pelatihan hanya perlu melakukan aktivasi GitHub Pages satu kali saja di awal (membutuhkan waktu kurang dari 30 detik):

  1. Buka repositori GitHub di browser → menu Settings → menu Pages.
  2. Pada bilah Build and deployment → Branch: pilih main dan direktori / (root) → Klik Save.

Setelah tombol *Save* tersebut diklik, **seluruh pekerjaan deployment Anda telah selesai untuk selamanya**. Setiap kali Anda meminta AI memprogram fitur baru, memperbaiki teks, atau memperbarui foto cagar budaya:

  • AI menjalankan perintah git commit dan git push origin main di latar belakang komputer Anda.
  • Server GitHub secara otomatis mendeteksi perubahan tersebut melalui *GitHub Actions Webhook*.
  • Dalam tempo 30–60 detik, alamat website publik Anda (https://username.github.io/repo/) otomatis terbarui dan dapat langsung diakses dari browser smartphone di seluruh dunia tanpa perlu me-refresh server atau mengunggah berkas apa pun lagi.

Bagian IX: Glosarium Istilah & Rujukan Akademik

Glosarium Geospasial & Web Development:

  • CRS (Coordinate Reference System): Sistem koordinat untuk memproyeksikan permukaan lengkung bumi ke dalam representasi matematis.
  • WGS84 (EPSG:4326): Datum geodesi standar global yang digunakan oleh GPS dan Leaflet.js dengan unit derajat desimal.
  • GeoJSON: Format standar berbasis JSON untuk menyandikan aneka struktur data geografis (Point, LineString, Polygon, FeatureCollection).
  • Lat/Lng Inversion: Galat fatal akibat tertukarnya urutan lintang (Latitude) dan bujur (Longitude), menyebabkan fitur spasial berpindah posisi ke belahan bumi lain.
  • Zero-Manual Deployment: Pola pengembangan web di mana pengembang tidak perlu lagi menjalankan perintah terminal Git atau mengunggah berkas secara manual ke server hosting; seluruh siklus kompilasi dan pengiriman kode ditangani secara mandiri oleh Agentic AI.
  • Native Lazy Loading: Atribut peramban (loading="lazy") yang menunda pengunduhan gambar hingga pengguna menggulir layar mendekati posisi gambar tersebut, sangat krusial untuk menghemat memori perangkat seluler.
  • Agentic AI: Model kecerdasan buatan tingkat lanjut yang memiliki kapabilitas menggunakan alat (*tool use*), mengeksekusi perintah terminal, membaca basis kode, dan memperbaiki galat pemrograman secara mandiri.
